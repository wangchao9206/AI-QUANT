# 独立后台管理

入口为主系统顶部的「后台管理 ↗」，地址 `/admin`。该页面使用独立布局、导航和返回主系统按钮，不把管理模块加入交易系统侧栏。个人账号页只保留工作空间切换与创建、密码与邮箱、个人接口密钥。

## 管理范围

- 平台管理员可管理全部租户、平台账号及全局菜单；初始账号 `admin` 首次登录必须修改密码。
- 租户 OWNER / ADMIN 可进入当前租户后台，查看成员、管理业务角色、查看日志、撤销当前租户访问。只有 OWNER 或平台管理员能分配固定角色和自定义角色。租户管理员不能修改全局账号状态或平台管理员身份。
- 普通 MEMBER / VIEWER 无后台入口，后台接口也会拒绝访问。默认租户、最后一个所有者、当前平台管理员自撤权等操作受到保护。

## 模块

1. 租户管理：搜索、分页、新建、改名、停用与恢复。停用撤销租户会话及接口密钥，保留业务数据。
2. 用户管理：搜索、创建账号、显示名称、全局启停、重置初始密码、平台身份授权。初始密码遵循「账号 + 123456」，必须首次修改。填写邮箱时走真实邮件验证，SMTP 未配置时明确返回错误；不使用模拟验证码。
3. 角色与权限：按租户管理自定义角色，配置各业务模块读取与操作权限，提供停用、删除与版本冲突检查。
4. 用户授权：使用账号或邮箱添加现有用户，调整固定角色与自定义角色，预览最终有效权限。未分配自定义角色时继承固定角色；分配后普通成员按自定义角色并集授权；停用已分配角色不会恢复默认权限。VIEWER 与 READ 密钥始终只读。OWNER / ADMIN 保留固定管理权限。
5. 菜单管理：平台级菜单名称、分组、顺序、显示状态；只允许已有站内路由，拒绝外部地址、脚本、循环父子关系。菜单可见性与 API 权限分别校验。
6. 会话与密钥：查询和撤销会话、查看密钥元数据并撤销，不显示密钥原文。撤销阻止后续请求，已发起请求不做追溯回滚。
7. 操作日志：账号写操作、后台查询、业务写请求及导出请求的用户、租户、方法、路径、状态、耗时、追踪号；不保存正文、查询参数、密码、验证码和令牌。不记录自动行情轮询。
8. 授权与变更记录：搜索历史操作，新后台管理变更事务内保存前后状态。旧记录可能没有快照。支持详情对照与当前页 CSV 导出，导出进行公式转义。

日志界面不提供修改或删除。当前没有自动保留期限或归档任务，需要结合后续使用量另行配置。

## 接口与数据

管理接口位于 `/api/v1/auth/manage`，要求浏览器会话、首次改密、CSRF 与管理权限。Gateway 每次业务请求在线重新计算权限，隐藏按钮或菜单不能替代服务端校验。内部操作记录接口仅接受身份内部密钥，不经公共网关暴露。

新增 Flyway `identity V2` 为增量迁移，包含租户角色、角色分配、菜单和操作记录表，并扩展审计快照字段。保留既有租户隔离与账号验证流程。SMTP 变量和配置步骤见 [accounts.md](accounts.md)。
