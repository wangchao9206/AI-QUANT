# 三种专家视角后的最终裁决

这是综合E01/E02/E03的产品负责人设计判断，不是三个真人专家的外部背书，也不是模拟访谈多数票。三份独立原评审保留，以下说明如何修改工作提案。

| 裁决 | 专家意见与关联需求 | 最终处理 | 尚待验证 |
| --- | --- | --- | --- |
| D01 先聚焦谁 | E01主观/半系统化优先；E02要求金融契约；E03后置机构大范围。P01/P03/P04/P05/P09是第一条闭环，P06/P08保留专业路径 | 核心定位决策与训练；企业套保/完整组合风控/真实执行不在一期 | 真实活跃用户的任务频率、付费和数据能力，没有市场规模结论 |
| D02 五入口 | 三者有条件接受，均反对仅换菜单。P01-N1、P05-N4、P06-N1 | 五入口作为目标外壳，专业工作区和旧深链保留；先验证纵向对象链 | 今日与交易台的默认比例、专业期权是否固定快捷入口 |
| D03 首页 | 三者反对所有人强制进入今日。P03-N1与P05/P06有冲突 | 新用户默认今日；可恢复上次图表/实验/风险概览，仅改布局不改逻辑 | 真实登录后首个任务与回访路径 |
| D04 是否每次建档案 | E03反对看图也填表；E01支持快查；E02反对主观计划强制发布工作流 | 无case浏览合法；保存观察/计划才建轻量引用；手工计划与策略计划并行 | 用户愿意何时保存，最少必要字段 |
| D05 什么需要统一 | E03反对万能可变Case和双份账本；E02要求原版本/成本；E01要求恢复任务 | 统一身份、时间与合约/证据契约；原WF/Chan/monitor/paper各自权威；状态分别保存 | 适配器和旧深链的详细工程量 |
| D06 预测怎么变好 | E02反对界面改版承诺alpha，三者反对分数等于胜率。P01-N2/P06-N2/P08-N2 | 五种输出契约，目标与周期、反证、费用、样本、校准范围明确；新数据检验独立于UX验收 | 新预测是否超越基准、能否校准，必须等未触碰数据 |
| D07 研究是否被门槛堵死 | E02提出计算/统计/执行三轴，E01区分浏览与风险动作，E03要求服务端资格 | 不用单个tradeQualified控制全站；未验证策略可进隔离研究模拟/研究提醒，不升级盈利身份 | 角色对标签的理解、合理人工覆盖边界 |
| D08 指标与缠论 | E01图层/专业深页；E02组件定义/确认延迟；E03保留run/structure | 方法成为工具层和规则组件，共享图表和证据引用，不删除原典和引擎对比 | 专业布局密度、跨周期理解 |
| D09 期权 | P02/P08要同风险多表达；三专家均反对把168结构报告当已支持组合交易 | P0预留legs与假设对象；P1b先做研究草稿/压力比较，专业链直达；保证金/行权/撮合独立立项 | 用户究竟需要研究还是执行，真实经纪商和历史数据覆盖 |
| D10 文化与内容 | E02不允许非实证进入交易资格；E01/E03保留用户资料与自选比较 | 提议默认行动依据只用可检验实证；文化内容/导师/书籍次级化保留，不自动改当前算法和用户记录 | 用户是否接受此定位，模型新版本需独立回归 |
| D11 迁移与风险 | E03要求归属导入/旧ID和四时间；E02不能未来泄漏；E01不能假就绪 | 上线前重新盘点现有会话/版本/事件，不硬编码先前19会话；本机记录预览导入；跨租户与回放实时硬隔离 | 实际迁移规模、旧权限菜单和历史数据完整性 |
| D12 如何排期与评价 | E03反对先定全量工期；E02模型研发不能按日历保证收益；E01先跑三条任务 | 周数仅资源假设，先估一个切片；保留等待型、计划型、研究型流程验收；真实用户与预测评价分开 | 真正任务耗时、错误、满意度和模型质量基线全部待采 |

## 未采纳的方案

不把所有界面合成一个长页面；不只改主菜单；不将相关指标当独立专家投票；不强迫所有用户先填账户或发布工作流；不删除学习正文和历史实验；不以一个风险/盈利布尔值控制所有研究；不把模型反对意见平均掉；不承诺UI改版提高预测准确率或投资收益。

## 审查后的三个补充

1. “一体化”验收是合约、时间、版本、来源和状态能连续追溯，不是页面数量少。
2. 产品既要能解释“现在等什么”，也要让专业用户继续独立研究；减少摩擦不能绕开权限与数据边界。
3. 本次交互原型用于检查对象和状态的理解，所有数据与模拟意向均为演示；没有连接任何生产账户，也不能作为已实现功能验收。

## 最终追溯审查修正

P06-N5组合风险/容量/资金分配与P07-N4企业套保为后置需求，验收待独立立项，不能借用期权草稿或权限测试冒充覆盖。T09补充同租户其他成员访问私人复盘、情绪与学习记录的拒绝测试，并与显式共享的团队风险计划区分。这是方案质量修正，不是完成了生产权限测试。
