# 活跃期货结果反推实验报告

实验主题：先识别已经发生的历史走势与进出场结果，再反推事前特征及其条件概率，并接入实时预警。

执行日期：2026年11月7日。报告生成时刻：2026-11-07T03:41:27+08:00。基础仓库提交（本轮扩展前）：ab8f55807c86162fa2ffc24d183695dff0fecac9。最终交付提交以仓库记录为准。

本轮不是寻找100%成功的公式。34个活跃品种形成87,976个带未来结果标签的决策截面，训练筛出11组历史条件线索。部分组合在后续时间和留出品种中出现相对基准的概率提升；概率提升不等于费用后必然盈利，也不代表已完成实盘前向验证。

报告由真实运行输出自动汇编。实测结果、解释及待验证事项分别标注；没有把未执行的实验、独立性或成交保证写成事实。完整代码、压缩事件、源指纹与失败记录另附。

# 一 实验问题与结果反推路线

用户目标是在实时看盘中筛选上涨、下跌、转折以及较合适的入场与离场机会。最终确认的方法是：先看历史结果，再推导过程；要求至少十几个活跃品种，而不是一两个品种的例子。

实际研究路线依次为：预设日线条件检验；针对失败结果加入量价、波动和退出过滤；补采15分钟真实合约；扩大到34个活跃品种；以未来结果作为历史标签，反向学习过去已知特征的组合；在分离的时间和品种中检验；将符合条件的历史概率线索用于预警。前几轮失败没有删除。

| 概念 | 本报告的含义 |
| --- | --- |
| 实测结果 | 从保存的数据、标签或事件计算出的样本数、条件频率、成本后变动和校验状态。 |
| 推导解释 | 为什么某类量价或位置可能与结果相关。相关性不是因果证明，解释不替代数据。 |
| 待验证假设 | 标签、样本、成本或市场状态改变后，规律能否继续成立。必须重新验证，不能填上想当然的数值。 |
| 概率目标 | P(特定未来结果标签成立 / 当前满足组合条件)，与同类对照比较。不是要求每次正确，也不是当前单次获利保证。 |

# 二 数据来源与完整性核对

日线研究使用81份标准实际交割合约和换月日线缓存，共137,790根记录，最长覆盖2016年至2026年10月30日，各品种历史长度不同。内部核对通过不等于独立行情源认证；缓存品种池也不是完整的历史可投资品种池。

最终反推研究单独采集34个当前活跃期货实际交割合约，原始15分钟柱 173,560 根；按生命周期断档规则清洗后 155,515 根。最近20个完整日线成交量中位数必须至少10,000手。所有34个候选在采集时通过该阈值。

# 三 结果标签的精确定义

令 t 为已经完成的15分钟柱，t+1 为其后继柱。特征只取截至 t 的分钟柱和当时已经完成的日线；历史执行假设从 t+1 的实际开盘价格开始。未来最多16根柱只用于构造训练标签，不进入实时特征计算。

| 结果目标 | 历史标签成立的条件 |
| --- | --- |
| 多头入场窗口 LONG_ENTRY | 未来16根内，上涨2个事前ATR先于下跌1个ATR，并且按费用假设计算后为正；同一柱同时触及两个门槛按不利路径。 |
| 空头入场窗口 SHORT_ENTRY | 未来16根内，下跌2个事前ATR先于上涨1个ATR，并且计成本后为正，规则与多头对称。 |
| 后续上行 UP_MOVE | 从次柱开盘起，第8根收盘至少高于入场参考价格1个事前ATR。 |
| 后续下行 DOWN_MOVE | 从次柱开盘起，第8根收盘至少低于入场参考价格1个事前ATR。 |
| 向上转折 LOW_TURN | 当前柱低点严格低于前4柱及后4柱低点，并在未来第8根收盘至少回升到当前收盘加1个ATR。 |
| 向下转折 HIGH_TURN | 当前柱高点严格高于前4柱及后4柱高点，并在未来第8根收盘至少回落到当前收盘减1个ATR。 |
| 多头回撤风险 EXIT_LONG | 未来8根最大不利波动至少1.5ATR，且第8根收盘仍低于入场参考价格0.5ATR。 |
| 空头反弹风险 EXIT_SHORT | 未来8根最大不利波动至少1.5ATR，且第8根收盘仍高于入场参考价格0.5ATR。 |

这些是本次可计算的结果定义，并非市场唯一的“最佳进出场”定义。转折概率14%不表示其余86%全部亏损：未形成严格局部转折仍可能上涨、横盘或小幅盈利。LONG_ENTRY标签频率与所有观察交易的成本后盈利比例也不是同一指标。

费用观察模型为每边名义金额1bp加每边一个不利跳动；止损／目标以连续价格距离作为研究门槛。这不是含排队、涨跌停、资金、保证金、每笔价格取整及完整历史经纪商费用的交易撮合器。收益为名义事件百分比，不是可投入账户的收益。

# 四 所有事前特征与计算公式

| 特征 | 实际计算 |
| --- | --- |
| 价格距日线MA5百分比 | 100 × (当前完整15分钟收盘 / 前5个完整日线收盘均值 - 1)。 |
| 价格距日线MA20百分比 | 100 × (当前完整15分钟收盘 / 前20个完整日线收盘均值 - 1)。 |
| 日线MA20五日斜率百分比 | 100 × (当前日线MA20 / 五个日线柱之前的MA20 - 1)。 |
| 日线MA5相对MA20百分比 | 100 × (日线MA5 / 日线MA20 - 1)。 |
| 价格距15分钟MA20除以ATR | (15分钟收盘 - 15分钟MA20) / ATR14。 |
| 15分钟MA5与MA20之差除以ATR | (15分钟MA5 - 15分钟MA20) / ATR14。 |
| 15分钟MA20五柱斜率除以ATR | (15分钟MA20 - 五柱前MA20) / ATR14。 |
| MACD双倍柱除以ATR | 2 × (DIF - DEA) / ATR14；DIF=EMA12-EMA26，DEA=EMA9(DIF)。EMA在最后120根内以首值初始化，训练／实时一致。 |
| RSI14简单均值 | 最近14个收盘变动的平均上涨额 / 平均上涨额与平均下跌额之和 ×100；无涨跌时50。是简单均值版本，不是Wilder递推。 |
| 当前柱量除以前20柱均量 | 当前完整柱成交量 / 此前20根完整柱平均成交量，不纳入当前柱进分母。 |
| 15分钟ATR占价格百分比 | ATR14 / 当前收盘 ×100；TR=max(高-低, abs(高-前收), abs(低-前收))，ATR取最近14个TR算术平均。 |
| 收盘在柱内的位置 | (收盘-最低)/(最高-最低)，取值0至1；零区间时0.5。 |
| 当前柱实体除以ATR | (当前收盘-当前开盘) / ATR14。 |
| 过去四柱价格变动除以ATR | (当前收盘-四柱前收盘) / ATR14。 |
| 持仓量五柱变化百分比 | 100 × (当前持仓量/五柱前持仓量 -1)。实现对缺失或无效分母使用0并返回缺失状态；本批原始15分钟输入缺失持仓字段数经核对为0。 |

特征函数至少需要120根分钟柱和25根已完成日线。未来柱、当前未完成日线及未来结果标签不作为特征。实时模型复用同一个函数，未另写一套近似指标。

# 五 推导规则与时间品种分离

每个结果目标分别训练一棵最大深度3的可解释二叉树。候选阈值只取训练样本特征的20%、40%、60%、80%分位数，以Gini不纯度降低选择分裂；每个叶子至少400个截面。该方法从带结果的样本反推最多三个事前条件的组合，不把教科书形态当作已证实规律。

叶子在训练集中的目标频率要比训练总体至少高3个百分点、目标成立至少30次、覆盖至少12个训练品种。每个目标最多保留两组，按训练概率提升排序。没有满足条件的目标不强补。最终得到11组；UP_MOVE没有满足本轮筛选限制的叶子，这不证明市场不存在上涨规律。

# 六 条件概率 对照与不确定性

条件概率 P(Y=1|C)=该组合中目标成立截面数/满足组合的截面数。同类基准按品种、分区、年月、小时分组，排除该截面自己后计算；最终按该组合截面加权。提升百分点=条件频率与同类基准频率之差，不是收益率。对照不是随机干预，不能作因果归因。

使用500次按周分块重抽样，保留同一周不同品种共同波动及部分序列相关；至少8周才给出约95%百分位区间。区间把已估计匹配基准视为固定，未完整传播基准估计误差；多目标、多叶子也没有做确证性的多重检验校正。因此分层名为探索性证据，不是统计确证或已校准的实时胜率。

样本数是决策截面，不是独立交易数：后续16柱标签会重叠，同一时间多个品种可能共同受市场因素影响。近期仅约5周，区间不报告，不能补造一个精确范围。

| 证据分层 | 实际含义 |
| --- | --- |
| 本次分块估计支持概率提升 | 时间检验和留出品种均有正提升，样本覆盖达门槛，且本次条件化区间下界为正；仍不是盈利证明。 |
| 概率改善待验证 | 两类检验的点估计改善，但区间可能跨零，继续观察。 |
| 品种或阶段依赖 | 不同品种或时间段的提升方向不一致，不统一判成失效，也不宣传成普适优势。 |
| 样本不足或近期走弱 | 明确显示不足或衰减；不要求100%成功，用层级、幅度和不确定性判断。 |

# 八 主要发现的解释与反例

实测：LOW_TURN_1 在时间检验中为474/3240=14.63%，匹配基准3.79%；留出品种为143/987=14.49%，基准3.82%。其组合是过去四柱价格变化不高于-0.354430个ATR、当前柱量大于此前20柱均量的1.238901倍、收盘位置高于柱内0.111111。

解释：短期下行后量能增加，同时收盘未停在极低位置，与随后形成严格局部低点的频率相关。这是相关性线索，不证明量能本身“造成”反转；也不表示每次下跌放量都能抄底。近期该标签频率约12.09%，同类基准约3.57%。

实测：HIGH_TURN_1 的镜像组合在时间检验约14.57%、基准3.80%；留出品种约14.06%、基准3.49%。它可以提示局部转折观察或多头风险复核，但该固定观察退出下的均净变动仍为负，不能直接称盈利做空系统。

实测：LONG_ENTRY_1 在时间检验约34.83%、基准31.61%，留出品种约38.84%、基准33.13%；两类区间均可跨零，属于概率改善待验证。其费用后平均观察变动分别约-0.0541%和-0.0137%。因此概率提升、名义盈亏比与实际期望要分开看。

实测：EXIT_SHORT_1 的空头反弹风险标签在时间检验约33.86%、基准30.57%，留出品种约40.52%、基准32.95%。它适合用于“是否需要复核空头风险”的提示；本次没有验证某条具体平仓委托的资金效果。

# 九 入场 离场与止损的使用边界

入场观察：优先查看条件是否属于当前模型范围、历史概率比匹配基准提升多少、跨品种是否一致、成本后观察均值是否为正、当前价格距原触发点有多远。不要将低频转折标签的概率直接当成盈利胜率。

离场观察：多头回撤风险、空头反弹风险、反向转折候选可以帮助复核持仓。实际何时平仓还取决于已有入场成本、持仓方向、保护价、交易成本和风险预算，本次未接入账户自动决策。

最适合的单点不能由历史局部最高／最低价直接搬到实时。历史标签允许使用未来确认“事后发生了什么”，但实时只能判断“目前特征与哪类历史结果更相似”。没有未来数据时，拐点始终是候选。
