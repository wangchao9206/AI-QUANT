# 四 未来结果标签与观察交易

Entry next 15-minute open. LONG/SHORT: +2 prior ATR before -1 ATR within 16 bars, positive after 1bp/side+1 tick/side; ambiguous bar loses. UP/DOWN: eight-bar close >1 ATR. Turns: four bars each side plus 8-bar 1ATR reversal. Exit-risk: 8-bar adverse excursion>=1.5ATR and terminal adverse>=.5ATR.

# 六 缠论实现与防止事后提前知道结构

使用已有aiquant-chan-v1研究内核，不是声称涵盖缠论原文所有递归定义的唯一标准实现。包含关系合并K线先封闭后识别分型；笔等待后继反向笔成立才封闭；线段使用特征序列规则；中枢采用最初三根已确认笔的固定交集。动态尾部不进入已确认结构特征。

一买／一卖候选包含两组非重叠趋势中枢背景、同向笔新极值及MACD面积减弱；二买／二卖采用一类候选后更高低点／更低高点；三类候选采用离开固定中枢后的严格不回中枢回测。它们仍为研究候选，会被价格越过失效边界撤销；只统计当时尚未失效且首次可知后8柱内的候选。

真实结构确认存在延迟。实验特征在每一个历史决策时点重新从过去窗口生成，保存当时可知的确认年龄。图上落在较早极值位置的候选不能回填到极值当时成交。固定滚动窗口可能与全生命周期引擎结构不同，这个窗口口径同时用于实时，不隐瞒边界敏感性。

# 十一 反馈推导与未被证实的部分

反馈1：增加周期和特征并未保证更好。多周期组有更多训练选中组合，但活跃口径下双分区改善组合数并未超过15分钟指标对照。应继续比较相同目标和风险预算的前瞻表现，不能按特征数量判断有效性。

反馈2：缠论单独组有部分标签概率改善，也有品种依赖和弱样本。B1／B2等稀少候选不足以分开验证；后续需增加历史合约生命周期和新日期，而不是把多个重复截面算成大量独立买点。

反馈3：少数普通指标与中枢条件结合可能提供筛选价值，但删除缠论条件的对照显示额外增益在留出品种中并不稳定。下一轮应在冻结阈值后新增未来样本，保留全部满足条件事件，检验概率校准、成本后期望与漂移。

反馈4：概率改善不能直接决定入场。标签的2ATR／1ATR赔率结构、达到目标的路径、费用及样本重叠均影响收益；表中平均净变动和压力结果为负时必须照实保留。离场标签也只代表后续不利路径概率，尚未验证相对“继续持仓”政策的实际收益差。

# 十二 接入预警的具体行为

新增“多周期指标＋缠论概率预警”模板，保存时固定15分钟决策节奏，可选多周期指标、缠论结构或二者结合，以及入场／离场／转折／走势方向。实际路径可能不含缠论，页面与证据明确标注。原有基础模型和日线MA预警保留；旧盘口定时扫描及每分钟快照继续停用。

模型读取601根15分钟记录，其中最后一根形成中柱剔除后得到600根完整柱；日线也剔除形成中柱。订阅上限保持48组，没有为30／60分钟增加SDK订阅。首次建立基线、切换模型版本不补发历史；每根新确认柱只记录一次，延迟恢复超过确认附近15秒不回放。行情过时、品种不在范围、活跃度不足、窗口不足时不造信号。

触发证据冻结模型版本、实验组、具体路径、全部当时特征、各背景柱数、缠论实现与窗口、特征／确认／可得时间、分区概率、基准、样本及去掉缠论后的对照。默认只提示双分区有改善的历史观察候选；探索范围仍明确标记弱证据，无自动下单。

这次历史实验与实时计算使用共享特征函数，已完成102组逐值一致性核对；代码测试另检查完整时钟桶、历史不足、无未来标签调用、无启动补发、去重、过时与活跃度抑制。真实开市前向命中和账户成交效果尚未验证，不把部署成功当成策略成功。

# 十三 局限与下一步的可检验假设

当前活跃主合约群体不是历史全市场可投资样本；品种间相关性和年度单一性限制泛化。

重复使用同一历史检验窗口会积累研究者自由度。本轮保留训练内搜索审计，但没有宣称消除过拟合。

全部策略观察以单个信号独立计算，允许重叠，不是合并持仓、资金使用与回撤控制后的组合业绩。

中枢未知值和固定滚动窗口影响条件解释；小于宽度阈值的路径可能利用缺结构状态，应在新样本中单独检查。

下一轮在冻结模型之后新增时间和更多历史交割合约；逐个目标比较模型的校准、覆盖率、概率提升、成本后期望和结构确认延迟。

5分钟及交易所原生30／60分钟周期应另采真实数据验证。不得将15分钟柱切碎伪造更细周期。
