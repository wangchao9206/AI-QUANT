# 道氏、威科夫与缠论两轮回测

2026-11-19 · 第一轮日线 MA5／MA10／MA20 · 第二轮 15／30／60 分钟

**纯 MA5 日线在全窗口领先，双倍成本下 +4.41%，2024–2025 年为 −1.58%。** 缠论日线单用有 33 笔、+0.43%，加任何一条均线后全窗净收益均下降。玻璃 FG701 的分钟轮中，15 分钟提供了更多候选，正收益组均只有一笔。两轮的三理论组合均零成交。

## 策略矩阵怎么定义

| 版本 | 独立触发或组合触发 |
| --- | --- |
| 基线 | 无均线时用普通突破回踩。MA5、MA10、MA20 列的基线是收盘从均线下方或线上首次上穿对应均线。 |
| 道氏 D | 方向状态由非多变为多时触发。日线要求同组另外两个合约序列的上一已完成周同时满足确认的高点、低点抬高。分钟使用 FG701 本身的同周期高点、低点结构代理。两者均用左右各 2 根的收盘摆动点，等右侧第 2 根完成后使用。 |
| 威科夫 W | 普通突破首次回踩确认时触发。突破为收盘越过前 20 根高点，回试在 10 根内发生，低点高于固定上沿且距离不超过 0.5 ATR，收盘高于开盘和前收盘。突破量须达到同交割合约此前 20 根中位数的 1.30 倍，收盘位置至少为柱内区间的 65%，回试均量不超过突破柱的 80%。 |
| 缠论 C | 已确认的三笔重叠近似中枢，首次回试守住中枢上沿时触发。等回试笔确认才发信号。 |
| 道氏＋威科夫 DW | W 触发时 D 处于多头状态。 |
| 道氏＋缠论 DC | C 触发时 D 处于多头状态。 |
| 威科夫＋缠论 WC | C 触发时，独立 W 机会已确认、尚未过期、已完成信号柱未触及 W 支撑，且仍在同一交割合约。 |
| 三者 DWC | C 触发，同时满足 D 多头和 W 有效。 |

第一轮的 MA 对七个理论变体只加一个背景条件，即确认日收盘高于对应 MA。无均线列保留七套原始理论规则。第二轮单独比较 K 线频率，各周期均不叠加 MA。WC 与 DWC 可引用此前已确认的 W 设置，有效期最多 10 根日线，分钟三个周期对应 8、4、2 根完整柱。W 的量价统计用其自身的突破与回试窗口。这一口径允许 W 先确认、C 后触发。日线和分钟均仅测试多头方向。理论原文与量化近似的依据见 [前轮研究](dow-wyckoff-chan-2026-11-19.md)。

## 执行、核验与适用范围

- 两轮固定 2 ATR 止损、4 ATR 目标，并统一移除价格结构失效退出，比较各组入场条件。日线持仓上限是 20 个交易日，真实换月按旧约开盘退出，按 0.5% 账户风险预算及保证金、名义敞口和流动性约束计算整手。前轮普通回踩有 92 笔，本轮退出规则统一后有 88 笔。
- 分钟柱完整收完后，使用下一根可观察的原始 1 分钟开盘。分钟持仓上限 240 个交易分钟，当交易日 14:59 开盘平仓，跨交易时段的休市间隔不计入持仓上限。分钟固定一手。两轮均按不利滑点和止损优先原则处理同柱双触。压力档把手续费和滑点翻倍。日线与分钟的仓位和收益单位不同，各自在本轮内比较。
- 完成日线 1,536 次、分钟 144 次账户模拟，覆盖 56 个策略配置、不同评分段与两档成本。完成 72 次日线、14 次分钟信号截断核验及 48 项相关测试。原始分钟按交易日与供应商日线 OHLCV 核对了 21 次。两次完整运行的输出 SHA-256 一致。
- 历史探索基于现有快照。日线包含同产业链相关合约，主力映射的历史发布时间未独立核验。分钟可完整核验的原始档案只有 FG701，其道氏规则使用单序列结构代理。两轮均无法恢复真实挂单排队、涨跌停可成交性及逐日经纪商费率。回测保留了每一组结果，未按成绩重新选择周期或阈值。
