主办方入口：[期货日报](https://ds.qhrb.com.cn/)。每个账户在JSON和页面导出中保留完整公开接口URL、届次、组别、截至日期、规范JSON组合SHA-256。接口响应归档于 `docs/research/data/mentor-2024-source-responses.json.gz`，包含URL和成功响应，供离线复核。它保存的是解析后的原始响应JSON，不声称是网络字节流哈希。

另外，已采集中证网首届金牛至赢期货大赛公开总榜前三个账户共306行逐日资金表，截止2026-10-16。字段包含权益、上日结存、当日结存、出入金、逐日盈亏、手续费、权利金等。保存于 `algorithm_service/mentor_settlement_snapshot.json`，来源响应归档于 `docs/research/data/mentor-settlement-source-responses.json.gz`。它们是另一个赛事的独立对照样本，尚未认定长期成功，不归入任何既有人物业绩。

中证网[公开排行榜](https://ifutures.cs.com.cn/trader/contestList)的账户及详情返回公开资金表，但所采集账户的 `access` 均为false。只读取公开资金表，未请求受限成交、持仓、平仓明细。现金检验按当日结存＝上日结存＋入金－出金＋逐日盈亏－手续费＋权利金收支，保留差额；权益与现金结存、期权市值及质押口径仍分开。

首次这一批与原有2026年三个公开账户合计：7个赛方汇总账户、865个日终净值点、190行期货/期权分品种平仓汇总；另有306行独立资金表。逐笔成交仍为0行，完整核验的人物交割单仍为0份。所有这些类别分别计数，禁止把865个净值点写成865笔成交。

## 本轮仍未取得的数据与具体障碍

- 期货日报公开移动端和桌面端：已核查公开客户端调用，取得上述原始汇总；这些调用没有逐笔成交价、时刻、开平方向和费用明细。
- 中证网：公开资金表已取得，成交明细权限未开放。不能用页面存在隐藏表头来证明可公开获得明细。
- 七禾实战排行：页面说明原始交易数据不公开，软件介绍所列成交明细功能需要账户授权。公开统计功能不意味着获得他人私有账单的权限。
- 期货日报第十六届旧平台和第十七/十八届旧专题：本轮HTTP读取超时；2023服务同族路径返回404，没有导入为有效数据。
- 傅海棠、林广茂等人物的访谈和网络复盘图：尚未定位可以核实账户归属、连续期间、真实成交与费用的完整原始文件。没有将回忆中的价格、示意K线买卖点补生成交。

拿到受限明细需要选手本人公开脱敏账单，或主办方/账户所有人授权的数据导出。行情账号只能取得行情，不能取得这些人的私有账单。本轮没有购买服务、发出对外联系、注册账户或尝试登录他人账户。

## 复现

在仓库根目录运行：

```powershell
python scripts/collect_mentor_history.py
python scripts/collect_public_settlements.py
```

历史采集只取公开榜单返回的四个目标昵称账户ID；资金表采集只取榜单返回的前三个ID，并顺序读取公开分页。全部账户成功且无重复日期才保存结果，失败保留旧快照；不枚举账号，不发送任何身份凭证。历史脚本支持 `--from-cache .test-tmp` 复用本轮开发缓存，采集时间保留文件时间，不伪装为重新取数。

本轮只完成描述性检验与证据导入，没有完成人物交易策略的因果验证。逐笔执行、初始持仓、完整费用和资金流、跨赛期失败样本缺失时，方法有效性继续标记待验证。
