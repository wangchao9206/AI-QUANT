# 燃油缠论结构研究 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在真实FU日线上检验三买/三卖的可执行研究版本，保留失败、确认延迟和普通突破对照，并发布到现有自主研究页面。
**Architecture:** 独立在线结构识别器与事件回测器；复用原现金账本、风险预算、因果换月价格及统计函数，不修改既有冻结研究引擎。扩展只读研究出版器，复用现有报告、账本和证据下载页面。
**Tech Stack:** Python dataclasses、pytest、NumPy、Matplotlib、JSON/CSV/gzip、SQLite、Vue/Vitest。

## 范围及选择

用户已批准上一轮提出的“三买/三卖、确认后执行、与突破回踩比较”的研究。现有1894根、2019-01-02至2026-10-27的FU真实交割合约快照可用；本轮不把连续合约价格当可成交价，不用日线伪造日内走势。优先复用完整已审计快照，分钟研究留待真实分钟数据。

研究三种途径的取舍：严格递归全部走势类型涉及更多边界定义；只做三笔重叠比较易验证但不能冒称严格缠论；仅做突破回踩又无法测出结构的增量。因此并列保留第67课特征序列线段的保守实现、明确标注的三笔近似以及普通回踩/直接突破对照。固定中心规则，不按后续窗口挑赢家。

## 看成绩前冻结的规则

1. 来源：第62课分型、笔，第67课特征序列线段，第20/21课三买的离开与次级别回抽思想。研究实现只取一个固定观察底层，不声称穷尽原著所有递归级别、所有特例或所有缠论实现。
2. 价格：调用现有 `causal_prices`，以观察到的换月开盘比例向前串接，绝不回调历史。下单、滑点、手续费和保证金使用真实交割合约原价。
3. 包含：向上合并高高/低高，向下合并高低/低低；第一段方向固定向上初始化，首个无包含的方向出现后随之更新。合并K线只有在后一根非包含K线到来才封闭，已封闭序列永不重画。
4. 分型：三个已封闭合并K线，中间高低均严格高于两侧为顶，反之为底；相等不成立。原始极值位置与确认时点分开保存。
5. 笔：相邻反向分型中心间距至少4根合并K线（邻域3/4/5），且价格方向相符；同向只延长最新候选极值。为避免端点延长回写，只有下一个合法反向端点出现后才发布前一笔。这是显式增加延迟的保守实现。
6. 线段：最初三笔有严格非空交集；数据起点可能位于未完成线段中，只在初始化时跳过没有三笔交集的未知前缀，一旦建立起点不再跳过。对反向笔构建特征序列，按段方向消除包含，观察相应顶/底分型。第一、二特征元素无缺口直接确认；有缺口需反向特征序列出现相反分型，等待期间被新极值超过则旧候选作废。已发布线段不撤销，不把候选笔/段当完成走势。
7. `CHAN_SEGMENT_T3`：三条连续已确认线段的严格非空交集形成研究中枢；界限冻结，重叠段可延长寿命；随后一条线段向上离开、紧接的向下线段最低点严格高于中枢上沿，形成买入事件，空头镜像。回抽极值之后至确认时点所有原始信号K线也不得触及中枢边界。事件只在回抽段确认时发出。采用一个观察底层的线段重叠研究口径，不等同于完整递归走势类型中枢。
8. `CHAN_PEN_T3`：同样规则改用已确认笔，显式标为三笔重叠近似，绝不称为严格原著三买/三卖。
9. `RANGE_RETEST`：收盘突破此前20日高/低形成候选（邻域15/20/25）；未来10根内回撤至边界外0.5ATR以内、整根不触及边界、收盘顺向且超过前收盘时确认。触及边界或超时取消。`CHANNEL_BREAKOUT` 使用相同前N日边界，首次收盘越界就发信号，控制等待回踩的影响。
10. 同一族中心规则均固定，无开发期选人；所有12个族×尺度组合全部运行，无论前几组是否失败。尺度只改变笔间距或突破窗口，不能偷换为独立机制。
11. 四组使用相同执行：完成日线确认、次日开盘；入场开盘若已回到无效边界则取消；不在换月日新开。上一日信号与当前开盘均用于限制手数，不能用当日收盘/高低/成交量选择交易数量。日线无法判断开盘是否排队，保留为条件性成交限制，不使用当日全日一价信息选择开盘入场。
12. 共同退出：固定2ATR止损、4ATR目标、满20根持仓日后次日开盘退出；前收盘回到入场结构边界以内或出现反向事件则次日开盘退出。止损/目标同日双触先止损；不利用日内有利路径；跳空损失不截断。目标限价不扣不利滑点，市价单扣滑点。换月平旧、不自动开新；窗口末假设平仓单列。
13. 风险沿用 `ResearchRisk`：min(初始资金,现金)×0.5%风险、保证金≤20%、名义敞口≤2倍、12%模型保证金率、前日量0.1%参与率、前日量至少10000，整数手不足一手不交易。模型费用=max(快照每手费用,名义金额万分之一)，市价单单边1跳，成本压力同时倍增手续费与滑点。历史逐日费率、涨跌停及盘口仍缺，不能称精确实盘复制。
14. 每窗口独立账户：开发统一第80根起至2023末、后续2024—2025、2026截至快照末日。所有历史曾参与其他研究，三个窗口都是历史探索，绝不宣称独立新样本外。真正前瞻须冻结之后取得的新数据。
15. 场景矩阵：4族×3尺度×3窗口×2成本×100万=72；中心追加4倍成本及1万/10万的1/2/4倍成本=84；中心100万追加延迟1日的1/2倍成本=24。合计180场景。延迟指信号确认后多等一根完成日线，期间失效则取消。
16. 预定晋级条件：中心开发≥30笔、后续窗口各≥15/8笔；三个窗口均基准及双倍成本净盈利；最大收盘回撤≤8%；各窗口去掉最好一笔仍正；邻域至少2/3双倍成本净盈利；开发12配置联合10日分块max-Sharpe校正p≤0.1。任一不满足不标为有效；零成交为样本不足，不算低回撤能力。
17. 保存信号/中枢/笔/线段审计、确认延迟、全场景、逐笔、拒单和失败日志；每笔成交可追溯极值、确认、信号和成交时点。只读发布不触发研究运行，不写模拟账户或实盘订单。

## Task 1：实现在线识别和因果性验证

**Files:** `backtesting/chanlun_research.py`, `tests/test_chanlun_research.py`。
先建立明确形态样例和未来追加不改旧事件测试，再实现封闭合并K线、候选端点、不可撤回笔、特征序列线段、中枢及镜像信号。验证包含、相等边界、有/无缺口、无效回抽和确认延迟。

Run: `python -m pytest tests/test_chanlun_research.py -q`。

## Task 2：实现事件执行和冻结研究脚本

**Files:** `backtesting/chanlun_research.py`, `scripts/research_fu_chanlun.py`。
复用现金账本与风险函数，覆盖次开成交、换月取消、双触止损优先、预算不足、跳空超预算及现金对账。脚本先保存协议/代码/数据指纹，再计算180场景；不覆盖已有冻结目录。生成机器可读结果、全部账本、CSV、因果性核验、图表和中文研究报告。

Run: `python scripts/research_fu_chanlun.py`。
