# 燃油第二轮修正：横盘门控与状态失效退出

这是看到第一轮失效后的探索性修正。历史的最后检验已经打开，本轮不得重新宣称2019—2026任何区间为未见样本，不能靠重复使用2026成绩认证策略。

## 依据与可证伪问题

只看第一轮2019—2023开发交易做归因：
- 区间反转在abs(SMA20−SMA60)/ATR14≤0.5时27笔、净盈亏约+22997.34；0.5至1区间26笔约−19692.02；>1区间80笔接近持平。
- 布林型均值回归在≤0.5区间反而18笔、约−13255.83，因此横盘过滤不是通用良方；将它作为反例对照，不能只保留区间反转的漂亮结果。

提出问题：区间反转只在均线分离较小时入场，持仓时条件失效就退出，能否改善原本的失效？预先冻结以下三种修正，不看结果再加参数。

1. RANGE_GATE：入场要求abs(SMA20−SMA60)≤0.5ATR14，原本均线回归退出保持。
2. REGIME_EXIT：在1基础上，横盘条件消失也于下一根开盘退出。
3. SHOCK_PAUSE：在2基础上，ATR14≤1.25ATR60；条件任一消失即触发下一根退出。
4. 对RANGE_REVERSION与BAND_REVERSION两类均跑；BAND作为与开发归因相反的对照。每类原有三种尺度，不调门控阈值，共18配置。
5. 开发、2024—2025、2026三个历史窗口均报告基准与双倍成本，共108组。用开发数据只选一次中心配置留观，再比较1万和10万元（核心100万元）在后两个窗口的实际可执行性，共8组。
6. 不修改风险预算、保护倍数、成本、成交规则、数据或旧轮规则。所有参数与旧引擎指纹一起冻结。
7. 即使结果改善也只记为事后探索候选。未来2026-10-27之后新增数据才能用于真正前瞻观察；不据此创建生产委托或更换历史成绩。
8. 若横盘过滤无效，记录机制失败，不改为逐个阈值搜索。下一轮应考虑燃油的原油驱动、期限结构和市场状态，而不是无休止组合技术阈值。

执行前确定中心留观选择顺序：先考虑开发完整交易≥20，再比较开发三个分段Sharpe的中位数，最后比较开发净盈亏；同分保留预定枚举顺序。尺度只作邻域诊断，不选非中心尺度。观察候选无论历史成绩如何都不能据此取得实盘有效标签。
