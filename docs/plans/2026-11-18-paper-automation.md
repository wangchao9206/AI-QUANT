# Paper automation Implementation Plan

**Goal:** 为实时多品种共用资金模拟账户增加逐合约后台策略执行，包含内置策略、已发布工作流及用户确认的 MA20＋日线MACD。

**Architecture:** 新建冻结参数的运行配置及决策日志；后台领取带租约的任务，读取真实行情和信号后，在租户事务内先锁同一资金账户、再复核运行配置及租约，复用原共享资金撮合。每合约只能有一个已启动策略，手动委托需先停止该合约策略。启动要求该合约空仓且无挂单；停止撤销该策略挂单，保留持仓供手动处理。页面关闭后后台继续，服务重启保留配置。无新配置自动启动。

**Tech Stack:** PostgreSQL/Flyway、Java17/Spring、Python/FastAPI、Vue3、现有Docker。

## Steps

1. V17：运行配置、租户边界、单合约活动唯一约束、决策日志及委托运行标识。旧数据不变。
2. Python扩展MA20_MACD：已完成日线MACD(12,26,9)方向过滤；21根已完成分钟线检测MA20真实穿越；逆向越过MA20三跳出场。10跳止损、无止盈、平仓后等新的分钟突破，由后端执行并去重。跨休市缺口不补造分钟数据。
3. 后台执行：复用身份授权检查、带过期校验的任务租约及租户RLS；复用共享资金预留/撮合。保护先于新信号，已持仓不加仓、不自动反手。日内策略收盘前一分钟尝试清仓，使用真实交易时段和有效报价，收盘窗口不再开仓。
4. 页面逐合约配置策略、冻结参数、启动/停止、刷新状态及查看决策。自动成交继续可记录私人心得。历史回放原有策略执行保留。
5. 隔离数据库验证幂等、租约/停止竞态、资金不足、权限失效、信号与保护及租户隔离；Python验证无未完成K线和未来日线泄漏；前端验证启停不混淆账户。备份后部署Docker并用隔离QA账户验证后台独立运行、日志、停止及页面关闭不依赖轮询。
