# 书籍在线预览实施计划

**Goal:** 由系统查找匹配书名、作者的正规在线阅读资源，在书籍感悟中预览，并保留外部平台阅读入口。

**Architecture:** 新增只读 `/api/v1/paper/books/{id}/preview`，调用微信读书公开检索元数据接口，严格匹配原著主标题与作者、排除下架/有声/解读书，校验返回阅读链接的 HTTPS 主机和路径。采用独立短超时与有界缓存；为已实际核对的《遥远的救世主》保留固定来源备选。独立前端组件管理加载、切书防串、版本选择和官方新窗口阅读；平台控制试读和登录/付费，不抓取正文或移除限制。

**Tech Stack:** Spring RestClient / Jackson / Vue 3 / sandboxed iframe / Vitest / JUnit。

核验资源（2026-10-27）：微信读书公开检索返回 bookId `3300227861`，标题《遥远的救世主（〈天道〉影视原著）》、作者豆豆、出版社作家出版社，readerLink `https://weread.qq.com/web/reader/24e32400813abbf82g011d29`。实际 GET 为 200，页面标题相符，没有 X-Frame-Options 或 frame-ancestors 限制；页面显示试读/登录提示。Google Books 仅找到书目，无预览证明；当当抓取失败，不把这些标成已验证的可读资源。

1. 实现公开资源检索、严格匹配、链接校验、缓存和已核验入口降级；不新增数据库迁移，不改写书籍或感悟。
2. 新增在线预览页签和显著入口，包含提供方、版本、作者、核对时间、试读说明与官方新窗口打开。
3. 验证同名/姊妹篇/解读书过滤、恶意链接拒绝、缓存与网络失败回退；验证新窗口 opener 隔离、切书竞态和无结果提示。
4. 完成前后端回归和构建，用真实浏览器检查官方入口、独立窗口和手机布局；保留平台登录/试读边界。
5. 部署本机并只读确认书籍/笔记/交易数据未改动，清理临时测试资源。

实测修正：官方页面虽然无 frame-ancestors/X-Frame-Options 限制，但内嵌自动化验收出现平台的第三方插件限制提示，不能作为可用的页内阅读器交付。最终采用原平台新窗口阅读，不嵌入 iframe，也不扩大既有 CSP，不更改平台检测或登录机制。

## 实施结果

步骤 1–5 已完成。前端完整 209 项通过，Java 25 项单元通过（10 项旧数据库测试按配置跳过）；本轮新镜像在独立数据库以真实 HTTP 验证原著、另建《天幕红尘》自动查找、缓存及笔记不被改写，全部通过。生产构建与镜像构建成功。

实际网站只读验收：预览 READY、正确资源 1 个、官方新窗口 URL 匹配、opener 隔离、无 iframe、手机无横向溢出、本站无运行时异常。书架及感悟计数未变，14 个交易账户的游标、时点、权益与版本未变，网关及服务健康。临时数据库、API 容器、网络、专用浏览器和内存页面已清理。最终实际站点截图与日志保留在忽略的 `.test-tmp`。
