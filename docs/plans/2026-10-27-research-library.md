# 自主研究上系统

范围：发布已完成的多品种初筛、燃油机制研究和燃油状态修正研究。保留原始冻结文件；只读 API 与页面不触发回测、推进观察、下单或发布策略。

1. 从原始报告、结果与逐笔账本生成带内容版本号的发布目录和只读 SQLite 查询库；保留原始证据下载。
2. 算法服务提供目录、详情、筛选分页、单场景曲线和逐笔交易、白名单下载，以及独立读取的最新影子账本。
3. 增加自主研究导航和页面：研究概览、失败日志、场景明细、完整报告、观察账本、下载。明确累计收益口径、独立账户、事后探索和按需更新。
4. 验证发布数据与原始账本一致、路径边界、分页和安全报告渲染；执行前端测试/构建，在实际服务中检查桌面与移动布局。部署前后核对既有模拟账户和阅读资料。

验收：三个批次合计 1390 个场景均可查询，包含亏损与零成交；全部交易和曲线可读取及下载；观察账本显示真实保存日期与状态；页面不产生业务写入。
