# 实时仿真图表修正

问题：模拟页面只有历史分钟账户接入分时/周期切换；LIVE账户继续调用已完成历史日线背景，并以账户旧估值时点截断，未自动刷新图表。

修正：LIVE图表读取当前实际交割合约的天勤实时K线，默认1分钟分时，支持全部既有图表周期；每2秒只读刷新，切换周期与刷新不提交委托、不启动策略。显示主行情时间、连接及新鲜度、形成中的末根K线；断线/过期/休市数据明确标识，禁止回退到历史日线冒充实时。账户估值时点单独标示。

沿用同一分时组件，LIVE轴使用实际合约交易时段，支持跨午夜夜盘，历史回放保留原冻结时钟。数据源携带真实交易日及交易时段，所有成交点依旧匹配实际合约。

验证包括源行情交易日/时段与周期测试、Java当前合约/新鲜度/无历史回退、前端自动刷新/过期/账户切换竞态/分时与K线及全部周期，以及隔离QA身份下的实际Docker行情检查。保留生产账号、持仓与心得数据。
