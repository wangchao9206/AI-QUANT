# 更新后动态模块404修复

旧浏览器入口仍引用 TodayView-DjLrnBNR.js，新镜像仅包含新哈希文件，因此旧页面导航时404。HTML已有no-store，仍不能更新已打开标签页内的模块映射。

修复：前端增加仅保存公开构建资源的命名卷，启动前把当前镜像assets归档，Nginx从归档提供哈希资源。替换容器保留旧文件及依赖，HTML仍从当前镜像提供且不缓存。用本机旧镜像恢复此次报错版本的全部assets，不修改文件内容或伪装新文件为旧哈希。

客户端补充仅针对动态模块/CSS加载失败的路由恢复，保留目标path/query/hash，sessionStorage限定5分钟内最多自动重新加载一次，离线、普通业务错误或无法保存恢复标记时不自动重载。

验证：跨容器重建后旧、新资源均200且MIME正确，未知assets仍404；HTML不缓存，资源保留nosniff/CSP等安全头；浏览器登录、今日、模拟交易与DKX正常。模拟资源404验证目标路由恢复和持续失败不会刷新循环。
