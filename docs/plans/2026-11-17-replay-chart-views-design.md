# 分时图、K线图及周期切换

用户确认需要真正的当日分时折线，以及可自由切换的K线视图，周期包含1、3、5、15、30、60分钟和日线。

- 在现有模拟账户图表上提供独立视图按钮与周期下拉框。默认分钟账户显示当日分时图，价格折线、MA20、成交量与可点击的成交点。固定交易时段轴保留未来空白区域，不补造价格。
- 图表切换只读取账户当前时点前已完成的数据，不推进模拟，不重新开户，不更改持仓、成交和心得。撮合周期在图表旁明确显示。
- 每个新分钟账户冻结原始1分钟档案和交易日归属；旧账户仅在原始来源SHA256一致时补充冻结数据。全部周期从同一冻结档案按交易分钟合成，跳过休市，保留收盘尾段，日线在交易日收盘后显示。
- 交易日归属沿用真实档案，周五夜盘可归周一。成交映射使用真实起止区间，避免夜盘和不同周期的标记错位。
- 以Python数据测试、Java聚合时点边界测试、Vue切换/分时线测试及真实Docker浏览器验收验证，并重建更新算法、模拟和网页服务。保留原账号、生产数据卷与原交易记录。
