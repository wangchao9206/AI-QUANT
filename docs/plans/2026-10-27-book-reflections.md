# 书籍感悟实施计划

**Goal:** 新增独立的书籍感悟模块，首本整理《遥远的救世主》，支持用户添加书籍及持久保存个人感悟。

**Architecture:** Vue 页面 `/books` 接入桌面与移动导航。内置解读使用独立内容文件，不伪装成原文引用或用户笔记；用户书架和感悟通过既有网关的 `/api/v1/paper/books` 存入 PostgreSQL，新增 V5 迁移，不修改旧迁移。写入携带请求编号，超时重试不重复保存；分页、书籍切换和失败保留草稿。

**Tech Stack:** Vue 3 / TypeScript / Spring JDBC / Flyway / PostgreSQL。

1. 新增 reading_book / reading_reflection 表与首本书元数据；实现列书、新建书、分页读感悟和追加感悟接口。
2. 内容覆盖核心思想、期货交易中的应用、误用边界及可自问的问题；引用已核对的 CME/NFA 投教来源，不添加未经核验的原著引文。
3. 实现书架、主题切换、内置阅读内容、添加书籍、个人感悟表单与历史记录；采用温暖纸色与朱红书脊的阅读界面，沿用项目字体与导航。
4. 验证请求幂等、分页和跨书籍隔离，以及异步切换/保存失败时草稿与请求编号保留；执行前端回归、生产构建和 Java/临时数据库测试。
5. 真实浏览器检查桌面与手机；构建更新本机服务、确认 V5 迁移、健康和既有交易账户不变。真实业务账户不用于测试写入，所有测试书籍/笔记写入隔离数据库或内存 fixture。

用户直接要求新增模块，继续在当前工作区实现并保留之前未提交的改动。

## 实施结果

步骤 1–5 全部完成。前端完整 204 项、Java 31 项通过（10 项实际隔离数据库集成场景），TypeScript/Vite 与两个 Linux 镜像构建通过。独立真实 HTTP 验收、桌面/手机浏览器的分页和超时重试验收通过；新入口增加后已修正移动端底部留白。

本机 V5 迁移成功，前端、模拟服务与网关均健康，实际网关首书读取正常。真实站点只读浏览确认两处导航入口、五项思想内容、空白个人感悟历史可用，无运行时异常及测试 POST。14 个交易账户的游标、市场时点、权益和版本与部署前逐项一致。独立数据库、API 容器、网络和浏览器示例服务均清理；截图与测试日志保留在忽略的 `.test-tmp`。
