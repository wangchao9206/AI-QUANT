# 模拟交易 K 线买卖点实施计划

**Goal:** 在历史和实时模拟交易日线中展示实际成交的买卖点和成交详情。

**Architecture:** 图表接口随固定 asOf 返回相同账户的成交流水，独立于列表分页及最近 200 条快照。前端按实际合约和已观察的交易日标签匹配成交，在现有 SVG 图表上叠加买卖标记及可点击详情。日线未完成或换月另一腿没有对应合约日线时说明未定位原因，不向前一根 K 线强行归属。

**Tech Stack:** Spring JDBC / Vue 3 / TypeScript / SVG / Vitest / JUnit。

1. 扩展 paper chart 的 fills 响应，严格约束 session、窗口与 asOf；复用流水映射，保留成交理由。
2. 编写交易日匹配工具及回归测试：历史时点、上海时区、夜盘跨周末、合约不匹配、未来数据、未完成日线。
3. 在 TongdaxinChart 增加可选 trades、默认显示开关、买卖图例、真实成交价定位、同根聚合和键盘/点击详情；不影响普通行情页。
4. 模拟页面传入图表同一次响应的 fills，刷新图表时随成交更新；说明未定位成交。
5. 验证前端回归及生产构建、Java 图表测试；使用隔离浏览器 fixture 检查桌面/手机标记详情。不在用户账户创建测试交易。
6. 构建并更新本地 frontend / paper-trading-service，确认健康，记录验证结果。

用户已直接要求实现，沿用现有界面布局和颜色，无需另行批准设计或提交已有工作区改动。
