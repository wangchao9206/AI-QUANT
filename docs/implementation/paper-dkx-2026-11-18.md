# 模拟图表 DKX

模拟账户图上默认显示 DKX(20)、MADKX(10)，共用一个显示开关，切换分时/K线或周期后保持开关状态。紫色实线是 DKX，青绿色虚线是 MADKX；读数随当前查看的柱更新。

分时用 1 分钟 OHLC；K线按选中的 1、3、5、15、30、60 分钟或日线计算。MID=(3C+O+H+L)/6；最近20根MID权重由当前20递减至最早1，除以210；信号线为10个DKX的简单均值。至少20/29根后分别显示；缺少OHLC或合约切换重新预热。只使用本柱及此前数据，实时未完成柱的数值随行情更新。

计算在 frontend/src/utils/dkx.ts，两种图形共享计算。指标值纳入价格轴边界，预热/缺口不补线。显示操作不会提交交易委托。

验证：56项前端回归测试通过（包括数值、OHLC权重、历史前缀不变、缺口、合约切换、分时截止时点、缩放及显示开关），TypeScript与生产构建通过。

实际Docker网页使用独立临时用户、真实FG701行情，逐一核对分时及1/5/15/30/60分钟、日线的DKX数值，验证切换图形、显示开关、手机布局与账户委托/成交数量不变。新周期订阅需等待完整历史数据到达，再对照最新柱；预热时允许留空。截图检查额外修正复选框被页面通用输入样式拉大的问题。

验收脚本：scripts/qa_paper_dkx.cjs；本地结果在忽略目录 .test-tmp/paper-dkx/。
