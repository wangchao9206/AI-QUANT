# 研究工作台接入决策档案与本机日志归档

日期：2026-11-07。代码基线：72292db，包含本轮中单独发布的决策列表末尾斜杠修复。当前阶段连接研究原文、决策档案与旧复盘，预测算法和收益校准未改动。

## 使用路径

有行情读取、研究读写及决策写入权限的用户，在品种研究页核算风险后，可点击“保存到服务端决策档案”。服务端直接调用现有研究核算接口并保存回执，不接受浏览器提交的计算结果作为服务端结果。核算与归档分别是明确动作；仅看图或资料不会建档。

在档案的“研究原文与来源版本”中可查看原动作、模式、模型版本、资料与计算时间、门槛、参数和完整快照。回研究工作台的链接携带原档案；再次核算后可追加到该档案，也可明确另建档案。实际交割月不同时，服务端拒绝附加到原月份，不自动换月。追加来源只更新活动时间，不改原事件、手工计划版本或已有模拟关联。

等待、持仓观察、减仓、退出评估、仅准备情景均保持原动作；归档不自动生成手工计划、委托或成交。空白手工草稿没有默认多头方向，需主动填写方向、保护和预算后另行核验。原研究中的账户、单日/总风险、杠杆等约束保留在快照中，并未自动变成手动模拟订单的约束。来源确认不是统计盈利验证。

## 本机日志归档

研究页的本机复盘日志提供逐条“预览导入服务端”。预览显示原计划、模式、动作、保存时间、自报状态、净盈亏、备注和内容指纹；确认归属后才建档。导入成功不会删除或重写本机记录。原savedAt是旧日志声明的计划保存时间，不证明备注的编辑时间或历史作者。

- 当前作用域必须与服务端签名身份的账号、租户一致；其他账号或工作空间的作用域会被拒绝。
- 未归属旧键不作为当前日志的自动回退。用户须主动展开并声明归属，再预览和确认导入。归属仍是用户声明，服务器无法证明旧本机记录的历史作者。
- 导入来源永久标注LOCAL_IMPORT/未经服务端核验；自报EXECUTED和actualPnl只保存为用户声明，不写入模拟账本，不提升为服务端核算。
- 相同完整内容按规范化内容指纹去重，JSON键顺序或排版不造成重复；仅改备注/状态等会保留为同一原计划档案的来源版本。同ID但计划内容不同会分开保留，不能覆盖原计划。
- 同时保留本次传输的原始JSON文本，可从档案下载。这里的原文是导入时传输的JSON，不宣称等于浏览器存储文件的原始字节；界面“来源指纹”是规范化内容指纹。
- 未核验的本机历史时点不用于“当时”图重建；用户可主动切换“现在”读取当前行情。

无决策服务权限的用户保留原有本机研究/日志流程，不会被静默导入。账号、工作空间或内容变化后，迟到的结果不关联到另一身份；确认导入前发现内容变化要求重新预览。

## 数据与权限

V11新增decision_research_source、decision_source_link及来源索引，旧事件字段允许空值以容纳研究来源。原事件默认仍为MONITOR_EVENT，原记录不迁移、不删除、不覆盖。

新来源与关联表均FORCE RLS，按tenant、owner及当前research.read权限过滤；应用角色仅可SELECT/INSERT，不能改写或删除来源。跨表外键包含租户与所有者。研究核算还要求research.write，导入/归档要求paper.write；所有新接口继续要求market.read，读取档案要求paper.read。仅有paper权限不能取得研究原文，撤销研究读取权限后来源会隐藏。

服务端回执按请求编号和规范化输入去重；本机预览保存不可变来源，确认时引用该来源ID，不重新信任浏览器传来的结果。没有新增真实下单、自动模拟下单、预警任务或盈利资格。
