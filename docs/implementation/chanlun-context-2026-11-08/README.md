# 缠论来源身份与跨模块回链

基线 `b5f1c30`，2026-11-08。本阶段继续P0，把实际合约的多周期观察接入行情/原计划上下文，并修复历史工作台的来源识别。没有修改缠论引擎、封存算法、模型参数或监控调度。

## 已落地

- 当前实际期货、研究、私人计划和专业期权的共享对象栏可进入“缠论多周期”。携带准确交割月、返回看盘周期和经过读取核验的原计划版本，进入后只形成草稿，不自动采集、创建观察或订阅。
- 多周期观察仍使用既有的30分/5分或日线/30分/5分独立主源。15分钟看盘周期仅供返回行情，不变成15分钟观察，也不被替换成其他周期的证据。
- 创建仅由明确操作触发；请求只含clientRequestId、symbol、frames和asOf，不把私人case/plan写入共享缠论记录。浏览关联保存在URL，不是不可变证据绑定，不证明旧计划在当时引用或知道了该观察。
- 恢复冻结观察前检查返回ID、请求合约、组合、原始价格口径、实际采集与重建时间、源帧和可显示边界。URL合约或周期与原记录冲突时停止展示，不换记录。不接受主连替代实际月份，也不将REPLAY/asOf参数降级为当前观察。
- 选中的结构同时固定observation、frame和structure；多个周期即使存在相同结构ID也不会混用。缺失周期/结构有明确原因，不选末条或另一周期替代。初始图窗会显示被选中的存档结构。
- 冻结记录可打开该月当前行情，并保留回链；共享对象栏会重新读取观察核验合约和结构，再返回原冻结记录。返回、刷新、URL撤掉观察标识、切月和权限变化都清理过期状态。当前行情与历史重建的身份、重建界限、实际采集时点分开显示。
- 私人原计划读取失败、指定版本缺失或合约不一致时，不能创建带该关联的观察。用户可明确点击“解除引用，进入独立观察草稿”，不会偷偷降级或自动创建。恢复未完成任务不会自动续跑；继续原请求仍需明确操作和写权限。
- 历史工作台、引擎对照、逐根训练增加实际来源条，显示数据集、品种、频率、摘要、价格口径和原记录时点。历史工作台不再固定显示燃油；恢复橡胶等存档时不会被目录首项覆盖。
- 历史工作台默认只读目录；新分析由“开始历史分析”触发。读取原典、判断或已有run也不自动新建分析。选择新引擎/数据集是新计算参数，不改已有结果；缓存按数据集ID与摘要隔离，存档版本不在当前目录时可读原证据，新计算需另选有效版本。
- 缠论导航按目标能力携带引用：run交给历史工作台/课堂/判断或对照，训练恢复使用session，多周期使用独立观察入口；不再把同一组run/structure盲目传给所有页面。

## 验证

- 前端81个文件、516项测试通过，类型检查与生产构建通过。包括旧功能回归、原来源不被目录覆盖、显式创建、周期/结构精确恢复、缺失引用、合约冲突、权限变化、迟到响应、初始图窗定位和导航边界。
- browser-qa.json使用完整应用与实际路由，9组流程覆盖行情→草稿→显式创建→冻结结构→当前行情→原结构、刷新、缺失结构、错月份、私人拒绝及历史存档身份。1440/390宽度无整页横向溢出，零运行时异常。
- 所有浏览器身份、行情、计划、观察和创建响应都是明确的合成夹具；只有一次显式的合成观察创建，历史工作台入口创建数为0，其他写请求为0；所有API均拦截，没有写生产库。截图有水印，不是缠论效果或投资收益的实证。
- pre-deploy.json/deployment.json核对正式环境的原记录ID及冻结结果指纹。基线有53份成功历史分析、1份多周期观察和1份引擎对照；对原result内容逐一核对，未被本次更新改写。原始ID/指纹映射仅保存在本机忽略目录，公开回执只含数量与摘要。
- archive-compatibility.json另行只读检查53份历史分析的runId/数据摘要匹配，以及1份多周期观察的合约、模式与柱合约身份；这些是已有记录的字段兼容性检查，不表示已逐张人工验看全部图表，也不是投资效果实验。
- 部署只替换frontend；identity、paper、chanlun镜像及数据库迁移版本保持不变。生产入口与已通过构建的本地入口逐字节一致，匿名业务API401。本轮未重跑未修改的Java引擎测试，也没有以生产数据注入验收样本。

验证中调整了旧测试依赖“进页自动计算”的操作步骤，并发现了初始深链结构不在默认图窗、来源失败缺少恢复入口、身份变化不应复用旧观察缓存等边界，均补充回归。最终日志摘要与暂存内容摘要分别见verification.json和release-manifest.json。

## 边界与剩余

这一步统一的是浏览身份和可恢复引用。没有把历史复权连续数据集变成当前交割月行情，没有新增多周期支持，也没有将研究候选升级为可盈利策略或计划执行资格。当前行情可独立读取；原缠论观察不可读取时明确标错，不保留冒充核验成功的返回链接。

已有雷达监控、策略实验、独立判断、对照与训练能力保留；没有合并它们的账本、改成统一模型分数或启用新任务。缠论证据写入私人决策档案的服务端不可变关联、统一监控/实验时间线及偏差归因仍待后续实施。布局偏好、私人画线跨设备恢复和预测/指标/策略契约也未在本轮完成。

## 复跑与回退

前端执行 `npm test` 和 `npm run build`。设置PLAYWRIGHT_MODULE与CHANLUN_CONTEXT_UI_URL，运行 `node scripts/qa_chanlun_context.cjs`。发布前运行 `python scripts/verify_chanlun_context_deployment.py --snapshot`，发布并完成本地生产构建后去掉参数运行只读核对。

沿用原部署模式和数据卷；回退使用pre-deploy.json中的前端旧镜像，保留全部旧记录。回退旧界面会恢复其原有默认计算行为，不能再宣称入口仅只读。
