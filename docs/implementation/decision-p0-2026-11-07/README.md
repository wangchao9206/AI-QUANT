# 决策工作台 P0-A 首条纵向流程

日期：2026-11-07。设计基线：9babb91。按最终方案先实施原事件→计划版本→手动模拟账户→私人复盘，不先重写全部导航。

## 本期可用行为

从“实盘看盘→期货机会预警”的真实触发记录点击“制定 / 查看计划”，服务端读取原事件，创建或恢复本人决策档案。也可从看盘页“我的决策档案”进入；列表服务端分页，刷新后恢复保存版本。

- 原合约、事件、规则版本、行情发生/特征柱/首次可知/系统记录时间与证据不可被后来编辑覆盖。同一用户重复打开同一事件不重复建档。
- 当时/现在两个图表视图分开。当时视图为当前可读历史的截断重建，不声称保存过完整原始行情；只读原事件保存的几何线，按时间锚点重新定位。锚点、确认时间或周期不可靠时不补造，旧窗口索引不直接套用。
- 计划包含方向、参考入场/保护/目标、手数、模拟资金、单笔预算、理由、失效条件、有效期。保存新版本保留旧版本；多标签页冲突返回409，不能覆盖。预算不足或计划已过期仍可保留研究草稿，不能进入新模拟。
- 后端核验实际合约、可交易状态、报价/检查时间、跳动单位、情景风险及保证金。按计划和现价的较不利者、双边佣金与每边2跳预留估算；跳空和滑点可能使损失超过预算。这里只覆盖手填模拟资金情景，不包含外部账户敞口，不提供盈利资格。
- 点击创建时后端重新核验，并用这份相同的报价/规格创建已有运行器的独立MANUAL/LIVE账户。计划版本与账户的关联持久化、幂等；模拟账户沿用工作空间共享权限，私人计划与复盘不随之公开；没有自动订单或成交。模拟页面从服务端读取当前所选账户的真实关联，不信任URL中的档案ID。手动订单的参数仍由用户填写，本计划的手数和保护价不会自动约束订单。
- 继续等待、放弃计划或模拟过程均可记录私人复盘，固定关联保存版本。实际订单、拒绝与成交仍查看既有模拟账本，不在复盘里补造收益。

## 权限与数据

网关沿用paper读写权限；新接口额外核验签名身份内的行情读取与paper读写权限，直接持只读签名请求写入也会被拒绝。身份服务在原内部签名中加入有效权限列表。

数据库新增四张表：decision_case、decision_plan、decision_review、decision_paper，均启用FORCE RLS，同时按tenant和owner隔离。同租户其他成员也不能读取私人计划和复盘；关联外键包含租户/所有者，不能拼接他人计划。未新增团队共享或自动审批。

迁移仅新增表、策略、授权和索引；不搬迁、不覆盖、不删除现有会话、本机研究日志、工作流版本或监控历史。关联计划的模拟账户受外键保护，删除冲突会解释为需保留复盘，可暂停运行。未关联的原有账户行为不变。

## 本期边界与后续

本期支持真实期货预警来源与手工计划；期权多腿、自动计划执行、回放模拟桥、按计划预算约束每笔手动委托、跨设备本机日志导入、计划绑定新预警、统一五入口和预测契约重构继续按方案分阶段实现。原有研究工作台本机日志保持原状，没有宣称已全部迁移。

预测算法、收益校准、模型权重和后台监控任务均未调整；没有将流程联通解释为预测或收益改善。下一步优先连接已有研究计划与本服务端档案，再逐步收敛入口和助手动作。

## 运维

只更新identity-service、market-service、paper-trading-service、frontend，沿用保存的部署模式，不重建数据卷。接口均在现有/api/v1/paper/**与market路由下；未增加对外端口。

回退运行镜像可使用pre-deploy.json记录的旧镜像ID。V10为增量结构，回退应用时保留新表和数据，不运行降级删除或重置数据卷。正式上线结果、迁移版本、健康状态与旧记录完整性以deployment.json为准。
