# 计划版本与已有预警任务关联

基线 `6c5efdf`，2026-11-07。P0 的下一步切片：在私人计划版本中保存已有同合约规则任务的引用，保留规则快照、运行状态核对及任务历史往返链接。

## 使用与边界

决策档案选中最新、已保存、未过期的计划，点击“选择已有同合约任务”。搜索按实际合约分页，仅可选择本页中合约完全相同的期货任务。服务端重新读取权威监控任务，核对身份、原计划及实际合约，不接受浏览器提交的规则快照。重复关联不新增记录，也不更新原快照。

规则的名称、版本、周期、参数、关联时启用状态保存到私人关联表。原任务继续由原调度器运行。本动作不创建任务、不自动启停、不将入场/保护/目标价写进共享任务、不产生订单或成交。

“核对当前任务”重新读取当前版本；版本、合约变化或任务归档时显示原因，原快照不覆盖。链接携带 monitor/case/plan，任务触发列表按任务筛选，返回档案恢复指定计划版本。任务页展示该任务全部历史，不能把这些记录都归因于计划有效期。新计划不继承旧版本关联，历史版本只读。

关联成功只更新档案的规则关联部分，保留页面上尚未保存的其他计划编辑。账号、工作空间、权限或计划变化后丢弃迟到结果。
