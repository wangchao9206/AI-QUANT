# 私人图表与页面模式恢复

2026-11-08，本阶段补齐实时看盘的私人图表保存和跨设备恢复。原产品输入仍是经授权的角色模拟，不是真实投资者访谈。本轮是软件实现与验证，没有新增交易规律实验或收益结论。

## 已落地范围

| 对象 | 保存内容 | 边界 |
| --- | --- | --- |
| 页面信息模式 | 简明 SIMPLE / 专业 PRO | 同一用户、同一工作空间；不增加业务权限 |
| 实时看盘图表 | 主题、K线/收盘线、副图、MA选择、自动参考线分组 | 使用当前行情实际交割月与周期，价格口径固定为未复权 |
| 手动画线 | 两点斜线、射线、水平线、平行通道及原始时间/价格锚点 | 每图最多100条；达到上限阻止新增，保留最早记录 |
| 本机旧画线 | 展开原始内容核对后导入本机草稿 | 旧格式没有账号归属，不自动应用或上传；原记录保留 |

图表标识为 `LIVE_FUTURES_UNADJUSTED:<实际合约>:<周期>`，例如 `RB2701:900`。支持当前实时看盘提供的15/30秒、1/3/5/15分钟、日/周/月周期。主连或其他无法明确实际月份的图表仅保留当前账号/工作空间的本机草稿，避免换月误用锚点。

## 使用与冲突处理

1. 登录后打开实时看盘的实际月份；服务端读取本人记录，本机有未保存草稿时优先保留草稿。读取不会发出保存请求。
2. 在“图表与画线同步”中明确选择“保存到本人账号”。另一设备使用同一账号、同一工作空间、同一合约与周期可恢复。页面模式通过页头“页面模式同步”单独保存。
3. 两设备修改同一旧版本时，后保存的一方得到409。页面显示本机草稿和云端内容，停止自动覆盖。
4. 可以采用云端内容，替换前先备份本机草稿；也可明确用本机草稿覆盖已读取的云端当前版本，仍需通过版本比较。期间再次发生更新会继续冲突。
5. “恢复上一个本机备份”只恢复本机草稿，再明确保存才上传。备份只有最近一次，存储受浏览器数据清理及可用性影响。

读取期间和保存期间的新编辑都保留。响应必须匹配用户、工作空间、文档类型和图表标识，账号切换后的延迟响应不应用。网络响应不确定时，原草稿重试使用相同请求编号，避免重复修订。已有命令之后又出现更新时，不把旧成功回执当作当前版本。

新缓存含用户和工作空间标识；旧全局页面模式不会自动归属于当前账号。损坏或不兼容的私人缓存保留原文，停止覆盖该缓存，新编辑可明确保存到账号。旧画线需展开核对，导入会先备份当前草稿；云端仍需另行保存。缺少原始行情锚点时只提示记录保留，不把锚点平移到新K线上。

## 服务端与权限

身份服务增加浏览器会话接口：

- GET/POST `/api/v1/auth/workspace/preferences`
- GET/POST `/api/v1/auth/workspace/charts/{symbol}/{period}`

使用现有会话、工作空间选择、CSRF和来源校验。请求不接受客户端指定的所有者。API Key不能访问账号管理接口。个人模式允许当前有效成员保存，包括VIEWER；图表另外检查当前 `market.read`。模式保存没有授予业务写入权限。移除成员或禁用账号后停止访问，历史记录仍保留。

迁移 `identity V4` 新增 `workspace_document` 和 `workspace_revision`。限定数据库角色 `aiquant_workspace` 没有登录、超级用户或绕过RLS权限；两表均强制按用户及工作空间隔离。角色不能读取账号表、修改所有者、更新或删除历史修订。当前文档和不可变修订在同一事务中写入；按命令与文档加事务锁，第一次并发创建也经过版本比较。

前后端校验支持字段、图形、MA集合、锚点数量、时区、正价格及载荷上限。服务端保留完整修订内容与请求编号。本轮页面展示当前云端与本机草稿比较，并提供最近一个本机备份；没有历史修订列表或任意版本回滚界面。
