# 五入口与今日待办

2026-11-07，继续产品重构的 P0 阶段。基线为 `64aaeec`。本阶段把现有工作区组织成五个主入口，并提供本人计划的只读待办汇总。

## 已交付

- 默认首页及无指定目标的登录落点为 `/today`。原 `/overview`、品种、期权、缠论、研究、工作流、模拟及档案深链继续使用原地址、参数和页面。
- 桌面与移动端主导航收敛为今日、机会、交易台、策略、复盘。机会内可切总览、消息、线索和目录；交易台保留行情、期权、缠论、模拟；策略保留研究工具、工作流、研究档案、回测；复盘保留私人档案和原个人总结。具体入口根据当前租户菜单和读取权限过滤，不强行显示未授权模块。
- 资料、人物、书籍、系统等入口收进“资料与设置”。自定义菜单标签与未归入标准组的内部链接保留；原菜单的分组节点参与展开，不成为额外一级入口。
- `GET /api/v1/paper/decisions/inbox` 沿用行情及 paper 读取权限、签名身份和现有 owner/tenant RLS。一次数据库查询使用同一快照和服务器时点计算全部本人档案的数量，再筛选、排序、分页；不从前20条记录推算总数，不逐条请求详情或实时行情。
- 今日显示全部档案、已过有效期、未来24小时内到期、模拟待复盘、尚未形成手工计划。每条链接原档案；最新计划有关联模拟时可打开对应账户。接口异常、错误响应、无权限、空数据与身份切换均有处理。

## 口径和边界

有效期只读取档案最新版本，旧计划仍保留但不重复计入待办。支持 ISO 字符串及 Jackson Instant 的数字秒表示，不改写原 JSON。未保存计划的研究观察为“尚未形成计划”。

“模拟待复盘”仅表示最新计划已关联模拟账户，尚未写该版本的 PAPER_REVIEW，且最近复盘不是 ABANDONED。WAITING 记录不会当成模拟过程复盘；历史版本的模拟与复盘不算作当前版本。没有任何成交、平仓或盈利推断。分类可重叠，计数不能相加当作独立档案数。

放弃备注没有被转换为新的计划状态；到期分类也不改变或关闭计划。“已过有效期”仍按保存的有效期汇总，最近的放弃备注会同时显示。

今日覆盖本人服务端档案及最新计划关联的模拟，不包含外部账户、未关联的模拟或未导入的本机日志。它是刷新时的只读快照，尚未增加定时通知、计划触发订阅或实时风险扫描。进入档案送模拟仍沿用服务端再次核验。
