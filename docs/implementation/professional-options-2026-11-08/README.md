# 专业期权工作区与交易上下文

基线 `30f2f0c`，2026-11-08。本轮继续P0，将专业期权链接入行情、私人计划和跨页恢复；没有修改定价模型、研究结论或交易执行器。

## 行为变化

- 行情、研究和计划的共享对象栏增加“专业期权链”入口，仅对实际期货交割月开放；主连仍可在对应期权盘口中经服务端解析实际月份，再从选定期权进入专业页。专业页没有把主连解释为某一固定交割月。
- 实时看盘选定的期权合约可直接进入专业风险与到期情景。专业页按目录元数据核对实际期货、链、到期日与所选合约，不使用产品前缀匹配月份。
- URL保存实际期货symbol、chain、option、原看盘period，以及独立情景的side/lots/rate/dividend。刷新和浏览器前进后退恢复同一表达；利率和股息率使用小数口径，例如rate=0.035对应界面3.5%。这些是用户假设，不是自动填入的市场利率。
- 原case/plan经过服务端私人档案读取核对。指定旧版本仍引用原版本；不存在的版本不替换成最新版。仅带case的入口会选取并固定当时最新保存版本，然后保持精确版本；报价快速返回也不会把这个关联冲掉。
- 期权→同月期货图表→专业期权的往返保留具体期权和情景参数；期货切月会丢弃旧期权引用。专业页主动切换标的月份或指数链时解除旧私人计划关联，原计划不修改。切换同一实际期货的其他期权到期链仍可保留同合约来源。
- 指定交割月/链不在目录时显示原请求，不选择目录首项；指定期权不在该链快照中时停止风险与情景展示，不替换其他行权价或认购认沽。没有显式选择期权时，取得实际标的价格后才按已有规则选择近似平值项，这只是研究默认选择。
- 返回的快照必须与所选链、标的类型、标的原始标识和到期日一致；情景响应必须对应所选期权、方向和手数。旧请求和旧身份的迟到结果被丢弃。
- 历史asOf/REPLAY请求、重复/冲突周期、无效标识、无效方向或手数等不读取当前链报价来补齐。缺少私人来源权限也不降级为成功关联。指数链仍可独立研究，不被包装成可交割期货，未附加期货行情回链。
- 默认无参数入口保留原有目录浏览。目录正在准备时可继续等待；用户筛选到空集合时不自动换回其他目录项。

## 边界

本页是当前期权链、单腿风险敏感度及到期情景。看盘period用于返回期货图表，不是期权链周期或预测期限；期权K线继续由实时看盘的对应期权页签承载。原计划依据时点和当前快照时点分别标明，历史计划不能证明当前链在历史时点可知。

期货计划仅作参考关联，未转成期权计划、预算、手数或执行资格。情景方向/手数独立保存；没有创建期权模拟仓位、真实订单、多腿成交、卖方保证金或组合风险执行器。本轮功能测试不是期权机会的盈利验证，也不代替此前的大样本研究要求。

共享对象栏在期权页标记“请求的期货标的”，实际链身份以下方目录与快照核验为准；核验失败时下方停止展示行情，不能把请求字符串当已匹配的链。

## 发布与复跑
