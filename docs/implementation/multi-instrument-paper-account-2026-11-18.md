# 实时仿真多品种共用资金

本次范围是实时、手动模拟账户。页面增加“添加 / 切换品种”、账户内合约标签和全部品种持仓表。主力代码解析为实际交割合约；切换只改变图表和下单目标。选择平仓会准备对应合约的委托，点击提交后才执行。

## 资金与持仓

`paper_session` 是唯一资金账户。V16 增加按租户、账户、实际合约唯一的 `paper_portfolio_position`，分别保存净持仓、真实合约规格、行情与估值。每次下单显式发送实际合约；成交使用该合约的乘数、跳价和手续费。

所有持仓及委托写入先锁同一个账户行，跨品种串行检查资金。可用资金 = 现金 + 全部浮动盈亏 − 全部持仓保证金 − 开仓挂单预留。成交按实际成交价再次检查资金；撤单、拒绝和成交释放预留。平仓挂单也占用对应合约的可平手数。滑点已体现在成交价，不重复从现金扣除。

旧实时手动账户首次添加或切换品种时，在事务内迁移原持仓并给原委托绑定实际合约；现金、成交 ID 和私人心得不变。升级不产生交易。新页面创建账户后启用多品种；启用失败时保留已创建账户，允许在该账户重试。历史回放、自动策略和受控计划/训练账户沿用原流程。

## 行情与记录

批量实际合约报价来自 TqSdk 执行快照，不读取日线背景。仅开市且报价有效的合约可以成交；部分行情失败时保留原观测并标明不可用。已有持仓缺少可用报价时阻止新增开仓。休市价格可用于显示估值。图表轮询仍只读；“刷新账户估值”刷新全部合约并检查挂单。

全部品种委托和成交仍在同一账户内分页展示。旧未绑定委托明确显示未绑定状态，不使用当前选中合约代填。私人心得继续绑定原成交，保留作者与租户隔离及版本检查。新持仓表启用租户 RLS，并使用租户、账户复合外键。
