# 模拟账户量化自动执行

实时多品种共用资金账户增加逐实际合约的后台策略运行。参数在启动时冻结，一份合约最多一份活动策略；不同合约继续共用原资金账户。仅在用户点击启动后运行，不自动接管现有账户。启动要求该合约空仓、无挂单；停止撤销对应策略挂单、释放预留，已有持仓保留供手动处理。

支持既有内置日线策略、可实时执行的已发布日线工作流 v1，以及 MA20_MACD。缠论工作流 v2 延续现有历史模拟和冻结观察限制，不从后台绕过。

## MA20＋日线MACD

使用已完成日线的 MACD(12,26,9) DIF/DEA 判断多空方向，最近21根已完成的1分钟线检测MA20的新穿越。向上穿越且日线多头开多，向下穿越且日线空头开空；逆向偏离MA20三跳平仓。默认每次1手、固定止损10跳、不设止盈；已持仓不加仓，平仓后等待新突破，不立即反手。图表显示周期不改变策略计算周期。日内配置根据真实日盘最后收盘时间，在最后一分钟尝试清仓；该交易日随后不再开仓。

## 后台与执行约束

V17 新增运行配置与决策日志，挂单绑定运行ID。后台每10秒评估活动任务，使用过期租约防止重复处理；所有成交写入先锁原资金账户，再复核运行启用状态、版本和租约。停止时清除租约，已领取任务不能继续成交。后台使用创建者的租户和身份重新进入RLS；行情计算前及成交前核验权限，失效时停止并撤销策略挂单。

策略委托复用原保证金预留、实际合约费用和撮合，不另建资金池。普通页面刷新不能撮合策略挂单。固定/ATR保护在新信号去重之前检查；信号计算失败但仍有有效报价时继续检查已有持仓止损。断线、休市或过期行情不补造价格，显示等待原因；保护成交仍依赖有效行情。
