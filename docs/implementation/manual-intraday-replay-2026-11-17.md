# 分钟手动模拟与逐笔心得

入口：<http://localhost:8088/paper>。已使用项目原有 Docker Compose 的 light 模式启动，模式保存于本机忽略文件。原账号、密码及生产数据卷保持原样。

## 使用

1. 登录后进入模拟交易，点击“新建试验”。选择实际合约 FG701（玻璃2701），周期可选1、3、5、15分钟。
2. 已核验的数据范围为2026-10-19至2026-11-16，共21个交易日、7,245根1分钟K线；夜盘按交易日归属筛选。数据来自本地真实TqSdk档案，不生成行情。
3. 默认手动交易、1手、固定止损10跳、交易日收盘清仓；创建时可调整，止损填0即关闭。不设自动止盈或自动反手。
4. 单步、5步或播放推进；历史委托从下一根K线撮合。图表展示已完成分钟K线、MA20与实际成交点，日线MACD只展示截至回放时点已完成日线的指标，供手动判断。
5. 每笔成交右侧点击“记录心得”，编辑后点击“保存本笔心得”。心得保存到PostgreSQL，仅本人可见，页面刷新后可重新读取。同笔并发修改采用版本检查，冲突保留本地草稿。

## 图表视图更新

分钟账户默认显示真正的当日分时折线，包含价格、MA20、成交量及可点击的实际成交点，未推进区域保留空白。图表上可随时切换“分时图 / K线图”；K线周期可选1、3、5、15、30、60分钟及日线。

切换视图只改变观察方式，不推进回放、不改变持仓或交易心得。每步推进的撮合周期在图表旁单独标示。30、60分钟按交易分钟累计合成并跳过休市；日线使用真实交易日归属，收盘后才展示。旧分钟账户在原始来源SHA256一致时自动补充冻结档案，来源变化时拒绝静默替换。

更新后额外通过4项Java周期与时点边界测试、26项相关前端检查及43项Python/API检查，生产构建通过。真实Docker浏览器已逐项切换全部七个周期并切回分时，验证旧账户档案兼容、成交点打开心得、刷新保存、手动开平仓及手机布局。

手续费按档案每边每手6元的模拟假设与账户费率计算值取较大者；滑点计入成交价，沿用原撮合和账本口径。该假设不表示用户实际期货账户历史费率。分钟OHLC无法还原同根内的逐笔先后，固定止损采用保守处理。

## 运行

在仓库根目录执行：

```powershell
python scripts/compose.py --mode light up -d --no-build
python scripts/compose.py ps
```

修改代码后重新构建对应服务。不要删除生产数据卷。历史档案通过现有 `data/history` 目录挂载，数据库使用原持久化卷。
