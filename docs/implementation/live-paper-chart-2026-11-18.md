# 实时仿真图表修正

实时账户此前仍使用历史已完成日线背景，并以账户上次估值时间截断；分时和周期切换仅为历史分钟账户接入。这会使LIVE账户主图停留在旧行情。

已修正：

- LIVE账户默认读取当前实际交割合约的实时1分钟分时图，支持1、3、5、15、30、60分钟和日线K线，不再调用历史日线背景接口。
- 图表每2秒只读刷新，保留观察位置，页面隐藏时暂停请求、恢复可见时立即刷新；账户及合约切换通过请求代次隔离迟到响应。
- 页面区分行情时间与账户估值时间，展示实时、休市、过期和连接状态，使用原报价时间判断新鲜度；无行情时显示订阅/不可用，不回退历史日线或把账户旧价格当作实时价格。
- 纳入形成中的当前分钟；分时轴由合约实际交易时段生成，支持跨午夜夜盘，交易日归属来自真实交易日历。
- 图表刷新不推进账户、不提交委托、不启动策略。账户估值与已有撮合逻辑继续通过“刷新账户估值”等原操作更新。

验证：214项Python行情与数据测试、33项相关前端检查、14项Java图表/报价检查通过，生产构建通过。实际Docker浏览器使用隔离QA账户，将其估值时间刻意设为旧日期，验证主图仍显示2026-11-18当天行情、持续只读刷新、七种K线周期、真实合约身份及手机布局，页面无脚本异常。验证过程中账户版本、估值时间、订单、成交及资金均未改变。
