# 私人计划的专属价位与到期提醒

2026-11-07，代码基线 `cac7f7e`。继续 P0：服务端保存计划版本的私人订阅，后台定时检查，站内保留原计划、行情和触发依据，并在“今日”汇总。原共享规则任务及旧盘口退役状态不变。

## 使用与触发口径

在决策档案保存最新且未过期的计划，选择“顺计划方向突破参考价”或“反计划方向回踩参考价”，显式启用本计划提醒。选择的是已保存版本；草稿修改后需先保存。方式在本版本订阅中冻结，改变方式需另存计划版本。暂停可以用于历史订阅，重新启用只允许最新、未过期的版本。

服务器每次完成检查后安排60秒后的下一次检查，最多4个并行工作线程、每人最多20个启用订阅；排队或上游耗时可能延迟。读取准确交割月、LIVE状态、FRESH报价和检查时间，时间均须在当前30秒内且不超前2秒。

- 多头顺向入场：上次价格小于入场参考、本次大于等于；多头回踩方向相反。空头入场方向反转。
- 多头保护：从保护价上方穿到下方或相等；目标：从目标价下方穿到上方或相等。空头方向反转。它们是参考价观察，没有推断持仓、成交或先后执行状态。
- 启用、恢复、休市/过时/异常恢复后的首笔有效数据只建基线。采样间隔超过90秒重新建基线，不推断缺失路径；重复或倒序报价不产生信号。
- 记录的是分钟采样穿越，不证明逐笔触达、K线收盘确认、入场资格或实际成交。一个跳跃可跨越多个参考价，分别保存观察。
- 同一计划的ENTRY/STOP/TARGET/EXPIRED各最多一条，由数据库唯一约束去重。暂停/恢复和服务重启均不清空旧记录。新计划版本有独立订阅，不自动继承启用。
- 到期使用服务器时钟，不要求休市时取得新行情。订阅到期记录后停止。暂停中的订阅不主动生成到期事件，过期版本不可恢复。

计划保存新版本会在同一事务中停止旧版本启用订阅，清除旧租约。后台在落库前重新锁定档案、核对最新版本、订阅修订号、工作者及实际租约时间；等待数据库锁后重新检查有效期及报价时间。暂停、新版本或租约过期的旧检查不能写回。

## 私人与权限边界

V13增量增加 decision_alert_subscription、decision_alert_event，均 FORCE RLS 按 tenant/owner 隔离，复合外键包含租户和所有者。前端读写均需 market.read、paper.read，修改和已读还需 paper.write。后台每次重新核验账号启用、验证状态、租户/成员身份与当前权限，失权则停止，授权服务异常则不生成提醒并等待恢复。

后台跨所有者枚举到期任务使用服务身份；结果写入重新进入该所有者的 RLS 事务。事件原文只能追加，应用角色仅可更新 acknowledged_at，不能修改证据或删除事件。共享市场监控没有收到私人计划参数，不产生实盘/模拟订单或成交。

本轮只提供站内持久提醒。“今日”可筛未读、标记已读，打开原计划的精确版本；档案展示当前状态、观测时间、前后采样价、计划参考和完整依据。页面打开时约15秒刷新可见状态，关闭页面不影响后台任务。不同身份的迟到响应不会进入新身份页面。
