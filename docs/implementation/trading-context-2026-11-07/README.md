# 交易上下文与跨页恢复

2026-11-07，基线 `b7f56a0`。本阶段继续P0，增加行情、品种、研究、私人档案、模拟账本之间的共享对象栏与可恢复链接；没有重写专业引擎或合并账本。

## 已实现

- 实时看盘支持URL中的准确symbol、period和tab，初次进入、刷新及浏览器前进/后退可恢复。支持既有9种周期，兼容seconds参数；重复/冲突周期、无效标识与历史回放参数有明确错误。
- 指定交割月不在目录时保留原请求身份、清空旧图并提示，不自动换当前主连。没有参数的旧入口仍按原默认目录选择；主动切月会移除旧case/plan/session/monitor等关联。
- 共享“交易上下文”栏显示当前合约、看盘周期、核验后的档案与计划版本，提供行情、研究、对应期权、品种资料、原计划和本版本已有模拟账本的链接。资料加载失败时仍可依靠核验后的对象返回。
- 私人关联通过服务端档案读取核验，指定版本不存在时拒绝替换成最新版。权限或身份变化后丢弃迟到结果。原档案时点与当前浏览分开标注；看盘周期保留，不更改研究服务自身的资料周期。
- 档案首次打开会把实际选中版本固定到URL，切版本可恢复；只改变看盘周期不会重新载入档案、丢弃草稿。研究来源回链保留所选版本及周期，品种选择器/交割月梯度切换保留周期并解除跨月关联。
- 既有任务链接携带实际合约/周期，直接打开监控页签及指定任务的触发记录；任务过滤会随URL变化更新。
- 模拟页从URL恢复指定账户，账户切换写回URL并支持后退；合约换月时重新核对共享对象栏。计划关联只读服务端for-session结果并交叉核验档案中的真实绑定，不信任URL附带的case/plan。历史模拟打开当前行情有明确提示，未调用推进、下单或创建账户。

## 边界

这一步统一对象与导航上下文，专业行情、研究、档案和模拟仍由各自页面承载。专业`/options`链表、缠论全部工作区、布局偏好保存、跨设备手动画线同步、预测契约和模拟委托对计划预算的约束尚未在本轮完成。对应期权入口复用实盘看盘已有的期权页签，按当前期货交割月查询。

共享栏不是行情快照或执行资格，行情时点/新鲜度继续由页面原数据源显示。主连保留研究身份，不被静默解释成实际交割月。历史模拟账户跳转当前行情不会修改账本时间。跨月会解除浏览关联，不改写服务端原计划、原事件、提醒或账户。

本轮只改前端，没有新API、数据库迁移、模型参数或监控调度变更。私人计划专属提醒继续沿用V13语义。

## 验证与发布

- 前端类型检查及生产构建通过；78个文件、448项测试通过。覆盖URL与月份身份、无效/历史上下文、真实账户关联与伪造引用、迟到响应、版本固定与草稿保留，以及既有图表和业务回归。
- browser-qa.json：完整应用与实际路由的7组流程，1440/390宽度、零运行时异常、零写请求。身份、行情、计划、账户均为明确合成夹具；研究资料故意返回失败，仅证明该失败场景中的上下文恢复，不表示验证了生产研究内容。截图有水印，不能当作实盘数据。
- pre-deploy.json为正式库只读数量与镜像基线，原始标识仅存本机忽略目录；deployment.json核对原账号、权限、会话、订单、成交、档案、订阅及事件标识保留、V13不变、后端镜像不变与前端健康。

只构建并发布frontend，沿用原部署模式，不重启后端或重建数据卷；回退使用pre-deploy.json的前端旧镜像。没有为验收注入生产记录。
