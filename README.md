# AI-QUANT

AI-QUANT 是一个面向红枣期货研究的前后端分离系统：Vue 3 提供研究界面，Spring Cloud Alibaba 负责网关、行情和策略编排，Python 算法服务负责实证计算，PostgreSQL 保存策略快照。

系统不生成演示行情，也不为缺失数据填充常量。上游不可用时，对应维度显示 `UNAVAILABLE` 并退出综合评分。

## 分析结构

最终交易评分只包含 11 个实证维度：

| 维度 | 主要真实输入 | 权重 |
| --- | --- | ---: |
| 产区气象与物候 | Open-Meteo 若羌、阿克苏、喀什预报 | 12% |
| 量价动能 | 东方财富实时行情、真实日 K | 13% |
| 技术指标 | 真实日 K | 12% |
| 新闻舆情 | 东方财富红枣资讯 | 8% |
| 供需压力 | 价格、成交量、持仓量 | 10% |
| 交割与交易规则 | 当前涨跌停和保证金规则 | 8% |
| 持仓拥挤度 | 真实历史持仓量 | 9% |
| 执行与风险 | ATR、支撑阻力和区间位置 | 10% |
| 主力跨期价差 | 实时合约价格 | 7% |
| 期限结构 | 多个真实合约价格曲线 | 6% |
| 流动性与波动状态 | 实时量价与历史波动 | 5% |

另有 3 个独立展示的传统文化参考：六爻、易经、奇门。它们根据 Asia/Shanghai 的真实当前时间，使用 `lunar-python` 计算四柱、节气、空亡和时九星，再做透明的时历映射；统一标记为“非实证文化参考”，分数和置信度为空、权重恒为 0，不参与综合评分、信号、仓位、目标价或止损。

## Docker 启动

```powershell
cd infrastructure
docker compose --env-file .env.example up -d --build
```

访问前端：http://127.0.0.1:8088

## 验证

```powershell
python -m pytest -q
cd frontend
npm run test
npm run build
```

每个维度输出数据状态、来源链接、观测时间、样本数和实际权重。第三方接口异常时系统显式降级，不将缓存或文化内容冒充为实时交易证据。本系统仅供研究，不构成投资建议或自动下单授权。
